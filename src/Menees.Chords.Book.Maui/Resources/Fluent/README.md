# Fluent System Icons

These 20-pixel Regular SVG assets come from Microsoft's Fluent UI System Icons repository:
https://github.com/microsoft/fluentui-system-icons/tree/main/assets

Retrieved September 15, 2026. The original SVG geometry is embedded and rendered by WinUI PathIcon, which inherits the current foreground color. No icon font, Blazor runtime, remote request, or third-party service is required at runtime.
