# Fluent System Icons

These 20-pixel Regular SVG assets come from Microsoft's Fluent UI System Icons repository:
https://github.com/microsoft/fluentui-system-icons/tree/main/assets

Initial assets retrieved September 15, 2026; action icons added September 19, 2026; Star and AttachArrowRight added September 20, 2026 for Make Default and Assign Learned Key. ArrowSync, CloudArrowDown, PlugConnected and PlugDisconnected added October 1, 2026 for the approved OneDrive toolbar actions. BracesVariable added October 4, 2026 for the requested editor conversion split button. TextSortAscending added October 28, 2026 for Sort by Name in the setlist editor. Tag added November 1, 2026 for song tagging; November 2 Edit Tags uses the same asset in song selection. CheckboxChecked and CheckboxUnchecked added November 3, 2026 for Select All and Unselect All. The original SVG geometry is embedded and rendered by WinUI PathIcon, which inherits the current foreground color. No icon font, Blazor runtime, remote request, or third-party service is required at runtime.
