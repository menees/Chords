Original path geometry and embedded comments are retained. Ukulele uses the supplied outline paths with pure black fills, omitting its three colored/background fill paths so it remains recognizable as a themed monochrome icon; line endings use repository CRLF. No license is inferred for files without a license comment. Keep source/license provenance with these assets for release preparation.

The native loader uniformly scales and centers the declared viewBox inside 20×20 DIP. It consumes filled SVG paths, including paths inside untransformed groups, and inherits the button foreground for light/dark themes. It is not a general SVG renderer for strokes, transforms, masks or gradients. The instrument selector maps stable standard-profile identities (or an exact standard name on an existing profile) to this artwork. Renaming a standard profile preserves its icon; custom profiles without a known icon retain a text caption.
